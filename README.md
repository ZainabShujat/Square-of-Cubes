# Square of Cubes

A topology-based spatial puzzle game built in Python and pygame.

Built around the mathematical identity:

1³ + 2³ + 3³ + ... + 9³ = 45² = 2025

The total area of all square tiles exactly fills a 45×45 board.

The challenge is not merely filling space,
but preserving long-term solvability and avoiding fragmented topology.

## Features
- Drag-and-drop square placement
- Movable placed tiles
- Dead-zone visualization
- Solvability scoring
- Tutorial system
- Dynamic UI scaling
- Sound effects and animations
